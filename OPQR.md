# OPQR
Optically Precepted Quotient Responsibility is the rule that assigns correction burden to the rendering interface when the terrain signal is intact but the observer-system cannot faithfully receive, model, tolerate, or transmit it.
Formal structure:

T = terrain
S = signal disclosed by T
I = interface/rendering stack
O = observing system
R = rendered output
T → S → I(O) → R
Distortion is:

D = R − S
OPQR states:

When S is present and D is produced by I, correction belongs to I.
Not to `T`.
Not to `S`.
Not to the source object.
**Core Rule**

Do not alter the terrain to satisfy a failed rendering layer.
The responsibility quotient is assigned like this:

Q_I = primary correction burden
Q_R = output disclosure burden
Q_O = observer/interface calibration burden
Q_T = zero unless the terrain identification itself is false
So the governing relation is:

Q_I + Q_R + Q_O > Q_T
when the mismatch is generated after the signal leaves the terrain.
**What OPQR Requires**

preserve the terrain
preserve the signal
identify the rendering stack
locate the distortion
correct the interface
disclose the transformation
never treat the transformed output as the original terrain
**What OPQR Forbids**

terrain deletion
signal laundering
comfort substitution
category inversion
interface absolutism
consensus recentering
observer-side intolerance converted into world-side censorship
